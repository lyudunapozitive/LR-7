# Лабораторна робота №7. Проєктування функцій, робота з просторами імен та рекурсивні алгоритми

**Варіант:** 20

## Завдання 1. Варіативна функція (Модуль діагностики кластера)
**Функція:** `diagnose_cluster_nodes(*nodes, **options)`
- Реалізовано прийом довільної кількості діагностичних кортежів (`*args`) та конфігураційних порогів (`**kwargs`) у модулі `functional_pipeline.py`.
- Виконано валідацію структури записів `(node_id, fault_count, uptime, cpu_load)`, типів даних та фізичних меж метрик вузлів кластера.
- Застосовано фільтрацію записів за параметрами за замовчуванням (`min_uptime`, `max_faults`, `max_cpu_load`, `only_unstable`).

## Завдання 2. Багатокритеріальне Lambda-сортування
**Компаратор:** `key=lambda item: (-item["fault_count"], item["uptime"])`
- Впорядковано відфільтровані записи вузлів кластера за допомогою функції вищого порядку `sorted()` та анонімного `lambda`-виразу.
- Забезпечено пріоритетне сортування за спаданням кількості збоїв (`Кількість_збоїв (desc)`) та вирішення колізій за зростанням часу безперервної роботи (`Uptime (asc)`).

## Завдання 3. Рекурсивний алгоритм (БПФ Кулі-Тьюкі)
**Функція:** `fft_recursive_instrumented(signal, tracker)`

**Реалізовані механізми:**
- Реалізовано рекурсивне швидке перетворення Фур'є (FFT) за алгоритмом Кулі-Тьюкі з розбиттям сигналу на парні (`signal[0::2]`) та непарні (`signal[1::2]`) відліки у модулі `recursive_algorithms.py`.
- Інтегровано програмний аудит глибини стека через клас `RecursionDepthTracker` із перевіркою системного ліміту `sys.getrecursionlimit()`.
- Проведено верифікацію точності розрахунків за допомогою `cmath.isclose()` з граничною похибкою `1e-9` та порівняння швидкодії з ітеративним аналогом `fft_iterative()`.
